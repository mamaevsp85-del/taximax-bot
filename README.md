# ТаксиМакс 🚕

Независимый бот такси для мессенджера **MAX** — один бот, три роли.

Официальная документация MAX API: https://dev.max.ru/docs-api

## Что это

Объединённый бот (в отличие от раздельных Telegram-ботов), в котором:

| Роль | Кто видит | Что умеет |
|---|---|---|
| 🚕 **Пассажир** | все | заказ такси (адрес текстом/геолокацией), расчёт цены, статус заказа, история, профиль |
| 🚗 **Водитель** | только одобренные админом | линия (выйти/уйти), покупка доступа (6/8/12 ч), приём заказов, жизненный цикл поездки, геолокация, заработок на баланс, статистика, профиль/авто |
| 🛠 **Админ** | из `ADMIN_USER_IDS` | модерация заявок водителей (одобрить/отклонить), список водителей, заказы, статистика |

### Логика ролей
- Новый пользователь видит **только пассажирское меню** + кнопку **«🚗 Стать водителем»** со ссылкой на аккаунт админа.
- По кнопке создаётся заявка (`pending`) и **админу приходит уведомление**.
- Админ жмёт «✅ Одобрить» → при следующем `/start` у пользователя появляется **выбор роли** (пассажир/водитель).
- Не одобрили — видит только пассажира.
- Админ видит **все три роли**.
- Водитель может быть и пассажиром: кнопка «🔄 Сменить роль».

## Установка и запуск

```bat
:: 1) зависимости (лучше в venv)
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt

:: 2) настройки — скопируйте .env.example -> .env и впишите токен
:: 3) запуск
.venv\Scripts\python main.py
```

Либо просто `run.bat` (создаёт venv при первом запуске).

Логи пишутся в `run.log`, данные (пользователи/заказы) — в `data/taxi_data.json`.

## Настройки (.env)

| Переменная | Назначение |
|---|---|
| `MAX_BOT_TOKEN` | токен бота (Платформа MAX → Чат-боты → Настройки) |
| `MAX_BASE_URL` | по умолчанию `https://platform-api.max.ru` (**домен `platform-api2.max.ru` из документации часто не резолвится** — если перестанет работать, поменяйте обратно) |
| `ADMIN_USER_IDS` | MAX user_id админов через запятую (главный: `14566736`) |
| `ADMIN_MAX_LINK` | ссылка на аккаунт админа для кнопки «Стать водителем» |
| `YANDEX_API_KEY` | ключ Яндекс Геокодера (адреса, обратный геокодинг) |
| `OPENROUTESERVICE_KEY` | опционально — резервный расчёт расстояний |
| `API_KEY` | ключ для приватных REST-эндпоинтов `api_server.py` (заголовок `X-API-Key` или `?api_key=`) |
| `WEBHOOK_SECRET` | опционально — секрет webhook-приёмника (заголовок `X-Webhook-Secret` или `?secret=`) |

## Единая база

Бот и Mini App работают с **одним файлом** `data/taxi_data.json`.

| Что запущено | Порт | Что делает |
|---|---|---|
| `python main.py` | — | бот, long polling MAX API |
| `python api_server.py` | 8080 | REST/WS API, webhook, раздача Mini App (использует функции `maximus_server`) |
| `python maximus_server.py` | 8765 | автономный Mini App-сервер (запасной вариант; для деплоя не нужен) |

Лаунчер `../MaximusTaxi/start-max.bat` поднимает `maximus_server.py` и туннель
(только локальная разработка).

> **⚠️ `MaximusTax/` — устаревшая автономная копия Mini-App** с собственной
> копией базы (`MaximusTax/data/`). Она исключена из git (`.gitignore`) и не
> используется на деплое. Единственный источник правды Mini-App —
> корневой `maximus_server.py` + `frontend/`. Правки делайте только там.


## Панель администратора

Доступна пользователям из `ADMIN_USER_IDS` (роль `admin`) и назначенным
**менеджерам**. Вход — кнопкой «🔄 Сменить роль» → «🛠 Админ» или командой
`/admin`. Полный перенос функционала из Telegram-версии
(`admin_bot_clean.py`): управление водителями/заказами/пассажирами,
редактирование тарифов (в т.ч. по городам и межгород), подробная статистика,
антиблокировки, редактирование контента и массовая рассылка.

## Важные технические детали

- **Домен API**: документация ссылается на `platform-api2.max.ru`, но этот домен не резолвится у многих провайдеров — используется `platform-api.max.ru` (проверено живыми запросами).
- **SSL**: используется `certifi` (иначе на Windows — `CERTIFICATE_VERIFY_FAILED`).
- **Токен** — только в заголовке `Authorization`, в query больше не поддерживается.
- **Лимит** — 2 сообщения/секунду в один диалог (соблюдается в `client._throttle`).
- **Команды бота** — `PATCH /me/commands`, поле `name` (не `command`).
- **Long polling** — явно указываются `types`, иначе часть апдейтов не приходит.
