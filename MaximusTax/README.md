# Maximus Taxi — мини-приложение

Открывается внутри бота MAX. Цвета взяты с логотипа: жёлтый, чёрный, белая бумага, синяя полоса.

## Как открыть

Запустите `start.bat`. Страница: http://127.0.0.1:8765/

База бота скопирована в `data/taxi_data.json`. Заказы, водители, тарифы и роли читаются и меняются там. Исходный файл в папке бота не удалён: пока бот и мини-приложение смотрят в разные файлы, новые заказы не общие. Расчёт маршрута по-прежнему идёт через геокодер бота, для него нужен интернет.

Роль переключается жёлтой кнопкой справа в шапке: пассажир, водитель, админ. Заказ, который создаёт пассажир, виден водителю в списке.

## Как подключить к боту

1. Выложите эту папку на https-хостинг. Адрес без пробелов, только латиница, цифры, точка и дефис.
2. В MAX для партнёров: Чат-боты → бот → Настройки → ссылка мини-приложения.
3. Кнопка запуска: «Открыть».

Скрипт `https://st.max.ru/js/max-web-app.js` сам подключается. Вне мессенджера приложение работает как обычная страница.

Диплинк с ролью: `https://max.ru/<бот>?startapp=passenger`, `driver` или `admin`.
